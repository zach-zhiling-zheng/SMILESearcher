# Acknowledgments

SMILESearcher is modified from [StarLiu714/SMILESearcher](https://github.com/StarLiu714/SMILESearcher), developed by Xinxin Liu. The starting version is [commit `757f893`](https://github.com/StarLiu714/SMILESearcher/commit/757f893aad819c89cb1e5c5dc0fc8961613e0ad4). The upstream Git history and GNU General Public License version 3 are retained.

Modifications dated **2026-09-27** integrate building-block lookup with MOF column handling and add an installable package, direct service clients, RDKit validation, resumable batches, audit outputs, examples, and tests. The Zheng Lab maintains this modified version.

Chemical resolution uses data and services from [PubChem](https://pubchem.ncbi.nlm.nih.gov/), the [NCI Chemical Identifier Resolver](https://cactus.nci.nih.gov/chemical/structure), [OPSIN](https://opsin.ch.cam.ac.uk/), and, when enabled, [Wikipedia](https://www.wikipedia.org/). Structure validation uses [RDKit](https://www.rdkit.org/).
